# my-book阅读器

一款在桌面上阅读本地 TXT 小说的轻量 Electron 应用。提供可调透明度、鼠标移出隐去内容、老板键等摸鱼阅读功能。小说文件始终在本机读取。

![my-book阅读器图标](build/icon.png)

> 当前仅提供 Windows 10 x64 版本。macOS、Linux 与其他架构暂未开放下载。

## 主要功能

- 打开或更换 TXT 文件；自动识别常见编码，也可手动切换编码解决乱码。
- 鼠标滚轮阅读，以及可自定义按键的一屏翻页。
- 拖动窗口边缘调整大小，正文随宽度重排；隐藏工具栏和滚动条。
- 调整背景、字体颜色和字体透明度，以及字体大小。
- 可单独开启老板键、鼠标移出隐去内容，或在未开启隐去时让文字自动滚动。
- 记住上次阅读的文件和位置，重新打开后继续阅读。

详细操作见 [使用说明](docs/使用说明.md)。

## 本地运行

在项目根目录执行：

~~~powershell
pnpm install
pnpm dev
~~~

## Windows 安装包

在 Windows 环境执行：

~~~powershell
pnpm build:win
~~~

安装包输出到 dist 目录，文件名形如 my-book-reader-1.0.0-setup.exe。dist、out 和 node_modules 不纳入源码仓库。

开发与打包说明见 [开发说明](docs/开发说明.md)。

## 隐私

TXT 正文只从用户选择的本地文件读取。应用在本机保存设置、最近打开的文件路径和阅读进度，不上传小说内容。
