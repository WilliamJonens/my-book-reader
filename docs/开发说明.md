# 开发说明

## 技术与平台

项目使用 Electron、Vue 3、TypeScript、electron-vite 和 pnpm。当前仅面向 Windows 10 x64 打包；其他平台的下载支持尚未开放。项目开发约束见根目录 [AGENTS.md](../AGENTS.md)。

## 目录

- src/main：Electron 主进程、文件选择、编码处理、设置与阅读进度。
- src/preload：主进程与 Vue 页面之间的受控接口。
- src/renderer：阅读界面、设置面板和交互。
- src/shared：主进程与页面共享的类型。
- resources/icon.png：运行时窗口和托盘图标。
- build/icon.png、build/icon.ico：Windows 打包图标。

## 常用命令

~~~powershell
pnpm install
pnpm dev
pnpm build:win
~~~

pnpm build:win 会先检查 TypeScript 并构建前端，再生成 Windows x64 NSIS 安装包。产物保存在 dist 目录；源码仓库不收录 node_modules、out 和 dist。

## 本地数据

应用使用 electron-store 保存设置、最近打开的文件路径与每本书的进度。为兼容更名前的版本，数据目录继续使用 Windows 的 %APPDATA%\desktop。修改该路径前应考虑已安装用户的迁移。
