# 使用说明

## 打开与更换小说

点击工具栏的“打开 TXT”选择本地 .txt 文件；读书时同一按钮显示“换一本”。也可在阅读区右键，选择“换一本 TXT”。文件编码会自动识别，若出现乱码，可用工具栏中的编码下拉框重新解码。

## 阅读与翻页

- 鼠标滚轮连续滚动正文。
- 默认按 PageDown / PageUp 翻动约一屏；在“设置”中可修改这两个快捷键。
- 拖动窗口边缘调整宽高，文字会随窗口宽度重排。
- 可在“设置”中调整字体大小、字体颜色与透明度，以及背景透明度。
- 可单独隐藏滚动条；隐藏工具栏后按 Ctrl+M 恢复，也可以右键选择“显示菜单”。
- 阅读器最上方有 10 像素的透明拖拽条，可用来移动窗口。

## 摸鱼操作

- **鼠标移出后隐去内容**：开启后，鼠标离开阅读器时文字与边框变为不可见；移回原位置即恢复。右键菜单和设置面板都能切换。
- **自动滚动**：在“鼠标移出后隐去内容”关闭且自动滚动已开启时，鼠标移出后开始滚动，移入后停止；滚动速度可设置。
- **老板键**：可单独启用并指定快捷键，用同一个快捷键隐藏或恢复整个窗口。

阅读器会记住每本书的阅读位置。正常关闭后再次打开，会恢复最近阅读的文件和位置。

## 快捷操作

| 操作 | 默认按键 |
| --- | --- |
| 下一屏 | PageDown |
| 上一屏 | PageUp |
| 显示或隐藏工具栏 | Ctrl+M |
| 打开或关闭设置 | Ctrl+, |

右键菜单还提供换书、翻页、复制选中文字和隐藏窗口。
